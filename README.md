# AmateurTab
This is a new tab website that lets you search up stuff you want but in a more stylish way! featuring a different background on every refresh and showing you the current date and time while also showing the news.

## Setup:

Clone the repo and install dependencies:

npm install

Click [here](https://unsplash.com/oauth/applications) to get your free API key

Create a .env file in the project root:

VITE_API_KEY=your_actual_key_here

Start the dev server:

npm run dev

Open the URL it prints (usually http://localhost:5173).

## Deploy your own copy:

Push this repo to GitHub

Add your API key as a repo secret named VITE_API_KEY (Settings → Secrets and variables → Actions)

Enable GitHub Pages with source set to "GitHub Actions" (Settings → Pages)

Push to main — the site builds and deploys automatically
